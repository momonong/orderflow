# 整合測試（新版）：文件與品項帳冊

本階段在既有 OrderFlow 應用內增設獨立試用介面與資料命名空間。它供合成資料驗證，保留 `/orderflow/` 管理頁及 `/orderflow/test/` 診斷頁；本階段不推送、合併或部署。

## 已確認的工作與界線

- 兩份參考 HTML 都在將文件內容整理成可核對、查找的品項。表姐版偏向 PDF 辨識後看訂單、發票與統計；同事版還有 Excel／人工輸入、發票和採購單對照、品號主檔。原型流程可借鏡，資料演算法須重新驗證。
- 使用者尚不能確認表姐是否處理出貨。新版只說「採購單」「發票」「文件數量差異」「尚未對應」；發票不代表收款或出貨，數量差不代表缺貨或庫存。
- 選檔、PDF／Excel 解析與核對在瀏覽器完成；按「確認並保存」前不得上傳原檔或候選資料。Google AI 必須另行明示同意；本階段不呼叫付費 Google，不使用真實商業文件，也不在不支援格式時靜默改用 AI/OCR。
- 新介面尚未整合 Google 辨識；既有管理頁的辨識能力維持原入口。此限制不代表取消原有能力。
- 正式管理及診斷資料不可被新版查詢、連結或更新。測試文件、品項、關聯及品號主檔都有獨立後端表與檔案目錄；API 逐次驗證登入會話與資料擁有者。

## 試用資料契約

文件種類只有採購單或發票。欄位含公司、單號、文件日期、幣別、品項的品號、原文件描述、數量、單位、單價與金額；不確定的值允許空白。來源記錄為 PDF、Excel 或人工，以及檔案雜湊、大小、解析候選值和人工確認值。主檔建議絕不覆寫文件描述或成交單價。

PDF 先沿用既有嚴格的瀏覽器端科雅採購憑單解析器；其他 PDF 明示不支援，可改為人工登錄。Excel 試用限 `.xlsx`、單一工作表、明確欄位對照及預覽；空值不猜測日期、單位、幣別或交易條件。公式、巨集、外部連結、掃描影像及超出大小／列數限制的檔案明示不支援。原檔只在確認保存後保存，並由相同會話授權查看。

同一會話的首次保存使用一次性請求識別以避免重複提交；編修帶文件修訂號，過期且內容不同的修訂回衝突，保留畫面中尚未存的修改。關聯由使用者指定「發票列 → 採購單列」，可撤回；多張採購單不得各自重複計入同一發票列的整筆數量。數量對照只採用明確分配且單位可比的數量，其他情況標為未知／未分配。品號主檔的描述與單位僅供建議，不能覆寫原文件欄位與成交價。文件金額按「採購單／發票 × 幣別」分開統計，不把同一交易兩種文件或不同幣別合成總額。CSV 匯出使用目前會話可讀的篩選結果，對試算表公式字首做防護。

## 試用身份限制與待決策

現有登入資料歸同一瀏覽器會話；驗證有效期約 8 小時，保有舊 cookie 時重新登入可繼續同一會話。清除 cookie、換瀏覽器或跨裝置不能保證找回試用資料。因此本階段的「保存重開」只保證同一會話，介面要明示；正式共享帳冊需另決定公司工作區、成員身份與資料遷移規則。此決策不以共用網站密碼推定。

原型中的多 PO 重複計入、取消發票仍計入、空白品號誤配、主檔覆蓋原值與無範圍重置均不得繼承。已存正式紀錄不默默匯入測試區；是否將來遷移及如何確認所有權，待人工決策。

## 本機完成條件

1. 舊頁面維持原行為；由「整合測試（新版）」進入新介面，後端舊 API 和新 API 互相不可讀寫資料。
2. 合成 PDF／Excel 及手動登錄可預覽、逐欄修改、確認後保存、同會話重開與查看原檔；選檔至確認前後端零寫入。
3. 測試重複提交、編修衝突、不同會話、撤回關聯、多 PO 分配、空品號、跨幣別、主檔建議保留原值、查詢與安全 CSV。
4. 以本機真實瀏覽器核對主要操作與窄畫面；不把合成測試當作表姐人工接受。

## 本機驗證紀錄（2026-10-02）

- 在獨立工作目錄與合成資料目錄驗證。Python 77 項回歸通過，既有 JavaScript 10 個測試入口通過，新 JavaScript 模組通過語法檢查，`git diff --check` 通過。測試綁定的是臨時 loopback 埠；未操作 ASUS 或正式入口。
- 本機瀏覽器實測人工登錄採購單／發票、斜線日期正規化、缺幣別與缺金額的分開提示、文件重新開啟、未存修改切換確認、品項明確連結與撤回、跨公司品號提示。主檔提示出現後，原文件描述、單位與交易價未被覆寫。
- 合成 `.xlsx` 實測瀏覽器端解壓、標題欄位對照、可讀候選值、逐欄核對與確認保存；確認前後端文件與原檔計數未增加。合成不支援版型 PDF 解析失敗後仍保留人工修改和原檔，確認保存後才新增文件與原檔。390px 視窗的整頁寬度不超過 viewport。
- 新 API 測試確認匿名 401、不同會話不可讀別人的文件，且新版文件不出現在原診斷／管理 bootstrap。單元測試涵蓋重複提交、修訂衝突、數量分配上限與撤回、原檔雜湊、CSV 公式字首、品號別名及上限。
- 尚未做真實文件、公司現場、Google 辨識、正式主機或跨裝置人工驗收。新版的 Google 辨識尚未整合；原管理頁功能維持。正式共享帳冊的身份與遷移規則仍待決策。
