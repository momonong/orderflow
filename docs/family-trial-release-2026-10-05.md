# OrderFlow 0.3.1 家人試用版候選

此文件描述候選版與發版閘門；GitHub 合併、ASUS 部署及人工試用須依各自回條確認，不能由本檔存在推定完成。

## 範圍

- 原管理與診斷頁可把自己原先上傳的 PDF 逐份加入共用清單。未加入的文件仍按會話隔離。整合試用頁可選用清單 PDF，但自行保存的 PDF 此版不能作為共用來源。
- 選用者在原管理／診斷頁取得自己的私有副本；新版整合試用頁先取到瀏覽器，逐欄確認並按「確認並保存」後才建立該會話的試用紀錄。選用本身不觸發 Google，也不轉移分享者的金鑰、工作或編修。
- 取消共用阻止新取用；先前已取得的副本保留。共用副本不得再分享。管理與診斷上限為 8 MiB；新版選用上限為 6 MiB，超限會在清單顯示不能選。
- 診斷報告區分本次瀏覽器上傳與共用取用；重新開頁選歷史文件不再標成本次上傳通過。
- `/orderflow/help/` 唯一對應 `docs/user-guide/index.html`；三個頁面提供入口，不開放整個 `docs/` 目錄。

## 發版與資料保護

ASUS 現用基線須先唯讀確認是 `b245b1a1da252f08a2f39a192346892d44832dc0`。`deploy/upgrade-asus-shared-trial.py` 只接受釘選 Git 提交的封存及 SHA-256，確認既有 service unit 和依賴未變，先複製 SQLite 做遷移試跑。沒有待處理工作時才停止 OrderFlow 寫入；停止後建立 root-only 原始檔案與 SQLite snapshot，逐檔核對舊資料，再遷移、切換 release 並啟動。健康閘門核對原管理、診斷、整合試用、手冊的位元與匿名 API 拒絕。任何停寫後失敗為 `HARD STOP`，保留現場及備份供人工對帳；不能盲目用舊快照覆寫可能已有新寫入的資料。

HP Tunnel、Caddy、SSH forward、入口與其他服務不在本版修改範圍。服務重啟會清除記憶體內暫存的 Google key，使用者需要自行重新設定。

## 驗證界限

候選版需通過 Python/JavaScript 回歸、舊資料加法遷移與停寫故障測試，以及 HTTP 權限、冪等、取消共用與檔案完整性檢查。合成 Excel 發票可進入瀏覽器欄位對照已驗。這些不能代替家人實際操作、公司網路、真 Google 請求與手冊手機排版的驗收。部署後另核對公開 HTTPS、ASUS runtime SHA、資料保留與認證邊界，並分別記錄結果。
